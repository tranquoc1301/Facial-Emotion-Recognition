# Facial Emotion Recognition

Dự án nhận diện cảm xúc khuôn mặt bằng mô hình học máy CNN.

## Cài đặt
- Cài python 3.10.18
- Tạo venv: `python -m venv .venv` 
- Kích hoạt: `source .venv/bin/activate` (Linux/macOS)
- Cài dependencies: `pip install -r requirements.txt`

## Chạy
- Tải dataset ở : https://www.kaggle.com/datasets/williamhaudrey/affect-net/data
- Run file recognize.py để nhận diện cảm xúc khuôn mặt bằng Webcam.

## Dependencies
Xem `requirements.txt`.
